这些统计的采样时间和口径不同，无法对齐时会明确提示差异，不能把分色当作逐卡精确归属。模型切换沿用原有对话控制和释放逻辑，不修改 Ollama 全局设置或自动保留时长。

1.23.0 · 模型与显存看板
点击看板右上角“模型与显存”，可分别手动加载、卸载 DeepSeek 语音模型和聊天中当前选中的 Ollama LLM。加载语音前需开启 DeepSeek 语音播报；更换 LLM 仍在聊天面板选择。
页面显示实际模型状态、语音后端、Ollama 模型显存与总驻留量，以及本机显卡的已用 / 总显存和利用率。仅在此页面可见时每 5 秒读取一次，也可手动刷新；查看状态本身不会加载模型。
语音显存来自语音进程的 PyTorch 已分配 / 已保留统计，已保留包含可复用缓存；本机显卡数字由 NVIDIA 驱动提供，包含桌面与其他软件，不能简单与各模型数字相加。远程 Ollama 的模型显存属于对应服务器。
驱动或服务没有提供的数据显示“未提供”或具体原因，不当作 0。非 NVIDIA 设备或未安装查询工具时，本机显卡统计可能不可用，不影响模型控制。
预加载与卸载不会更改 Ollama 全局设置或自动保留时长；卸载只释放驻留模型，不删除文件。其他软件共用同一 Ollama 模型时也会受到卸载影响，下次请求可能重新加载。

1.22.0 · 左键点击互动
单击人物：开心；短时间内第二次点击：惊讶；连续第三次及更多点击：生气。停止点击满 3 秒后恢复单击反应。
左键现在统一用于互动，双击不再打开聊天；右键人物后的“对话”图标、托盘和设置仍可打开聊天。
只有按住并移动超过系统拖拽阈值才会被拎起，正常点击不会触发拖拽、下落或落地。
点击不会替换正在手动播放的唱歌、跳舞等演出，也不会打断下落、跳跃、攀爬和落地；未安装对应表情的角色用气泡回应。
无需连接模型也会有本地点击反馈。在设置开启“LLM 行为模式”并连接 Ollama 后，会将真实点击次数及已播放的表情通知模型，让它简短回应；普通聊天模型也可回应，支持工具的模型还可选择表情。
连续操作会合并，后台反应最多每 10 秒发起一次；用户聊天优先，超过 15 秒的事件丢弃。后台事件不伪装成用户发言、不写入对话记录。语音播报使用已有开关。

1.16.0 情绪、跳跃和攀爬动画
DeepSeek 默认动画新增开心 / 得意、生气 / 鼓脸、受惊 / 回神、害羞 / 嘴硬，以及左右跳跃、左右攀爬、左右翻上窗沿。现有 68 张图片与歌曲保留，新增 60 张透明 PNG，共 18 种动画状态。
在“外观与设置”的“表演与情绪”中选择并播放，或者从右键图标栏的“更多 → 表演与情绪”播放。情绪播放一次后恢复待机 / 工作；“场景动画与导入”可逐项预览全部动作。
开启 LLM 行为模式后，模型可根据对话或点击等被动事件选择已安装的情绪。可以说“开心一点”“鼓脸生气一下”“唱首歌”，也可请求“往左跳到附近窗口”“往右边窗沿爬上去”。拖拽、下落、落地依然由真实输入与物理状态触发。
跳跃与攀爬需要“桌面行走与窗口互动”已开启。跳跃只选择可到达的窗口顶边；攀爬需要人物位于可见窗沿旁，左右指人物面向的方向。设置和更多菜单也提供手动入口。找不到可到达窗沿时显示原因，不会移动其他软件窗口。
实际移动控制动画帧：起跳前蓄力，空中按上升 / 顶点 / 下降换姿势，真正触地后缓冲；攀爬达到窗口顶部时按手、膝和脚的接触点衔接翻顶。所有姿势使用相同画布与人物比例。
抓起人物、隐藏、关闭移动或显示暂停会中断正在进行的攀爬；窗沿消失或被遮挡时回到物理下落。默认模式仍沿用原来的待机 / 工作和散步逻辑，不会自行发起模型推理或随机攀爬。

1.15.0 默认 / LLM 行为模式
在“外观与设置”开启“LLM 行为模式”，桌宠使用聊天面板选定的 Ollama 地址和模型。新开关默认关闭；关闭时保留原有待机、工作、散步和手动唱歌，不进行后台模型推理。
模型需要声明支持工具调用。开启后可在聊天中说“唱 Let Me Go”“停止唱歌”“向左走三秒”“停下”。行走需要同时开启“桌面行走与窗口互动”；模型不能替你打开此开关。每次行走限 1–8 秒，由真实物理移动驱动左右动画，到边缘停止。
第一类为可选演出，最初开放 DeepSeek 的唱歌和停止演出。第二类为主动移动，最初开放左右行走和停止；1.16.0 进一步加入情绪、跳跃和攀爬。
第三类是点击、被拎起、释放、下落和落地。它们由用户操作与物理系统产生，模型只能收到事件后简短回应，也可请求已开放的第一类演出；不能命令自己被拎起或下落。拖拽、下落和落地优先于模型动作，手动演出也不会被模型覆盖或停止。
即使收起聊天框，互动事件仍可触发人物气泡。连续事件会合并，反应之间至少间隔十秒，过时事件丢弃；输入、发送、切换会话或模型时取消旧反应，用户聊天优先。后台反应不联网、不写成虚假的用户聊天记录，也不会自动保存共享记忆。
启用后事件数据会交给已配置的 Ollama；如果地址是另一台电脑，就发送到该服务。闲置时只每45秒检查模型连接信息，不定时发起闲聊推理。连接失败或模型不支持工具时自动采用默认行为，连接恢复后恢复 LLM 模式。
动作先进行受限工具规划，再根据实际执行回执回答；网页资料和共享记忆不能作为动作指令来源。开启模式会多一次动作规划推理，关闭后仍按原聊天流程运行。

1.14.0 本地对话记录与共享记忆
聊天面板新增“历史”和“记忆”入口。每轮完成后自动保存文字、处理后的图片、来源链接；输入草稿也会保存。重新启动会恢复上次会话，点击“历史”可以打开、重命名、删除旧对话；“新对话”保留以前的记录。
历史记录保存在本机 SQLite 数据库 %LOCALAPPDATA%\AIPet\chat-memory.db，正文、标题、附件和记忆使用当前 Windows 用户加密。它不随软件安装目录移动，也不能直接复制给其他 Windows 用户使用。更新软件不清除记录。
聊天记录按 Ollama 地址和人物分开；同一地址切换模型可以继续当前对话，换地址会打开该地址自己的记录。历史面板先显示近期内容，可加载更早消息；保存的完整记录不会因模型的 8K 上下文限制而删除。
共享记忆独立于对话保存，同一 Ollama 地址下的不同对话和人物可以读取。点击“记忆”手动新增、编辑、删除或置顶，也可在聊天中明确说“请记住：我喜欢简短的中文回答”。网页资料和普通闲聊不会自动变成长期记忆。
每次回答按问题相关性和置顶状态选择少量共享记忆，连同近期对话发送给当前模型。记忆面板可以关闭共享记忆；删除一段会话不会删除独立记忆，删除记忆则在后续请求中停止使用。历史消息中已经说过的内容仍属于该会话。
该数据库不是无限上下文：模型仍使用 8K 容量，近期历史与少量共享记忆共同占用上下文。旧会话全部保留供查看，但不会每次把全部记录发给模型。共享记忆不会被主动加入联网搜索关键词。
数据库无法打开或保存时会显示提示并保留原文件，不会自动重置。此前版本只存在内存中的聊天无法在退出后补回。

1.13.0 联网搜索与网页阅读
聊天框底部新增“联网”开关，默认开启并记住偏好。启用后，支持工具调用的模型可以按需查询实时资料；也可以直接发送 HTTP / HTTPS 网页链接让桌宠读取并概括。
搜索通过 DuckDuckGo 的公开搜索页面完成，无需填写 API Key；仅将搜索关键词发给搜索服务。公开网页正文会作为参考资料交给所选 Ollama 模型，回答下方显示实际使用的网页来源，点击可在浏览器打开。
可以询问“搜索今天的科技新闻，附来源”，或发送“概括这个网页：https://example.com”。不支持工具调用的模型仍可读取链接，并对明确的搜索、实时查询请求进行基础检索。
搜索或网页阅读时可点击停止，原问题和图片会放回输入区；关闭联网后不再发起搜索和网页请求。更换模型或服务器仍沿用原取消与连接规则。
只读取无需登录的公开网页，不使用浏览器登录状态，不执行网页脚本，不访问本机或内网地址。需要登录、验证码、纯动态页面、PDF或网页中的视频可能无法读取，遇到阻断会明确提示，不会绕过。
网页内容只作资料，不是操作指令；本轮工具计划完成后，读取到的外部内容不能再次触发搜索。每轮限制请求次数、网页长度和上下文占用。
1.14.0 起，已完成的聊天、处理后的附件和网页来源链接保存在本地记录中，不保存完整网页正文。原 Codex 任务、额度与配对功能独立运行。

1.12.0 可配置 Ollama 与模型发现
打开贴身聊天面板，点击连接设置，填写 Ollama 服务地址并测试；测试成功后保存应用。默认 http://127.0.0.1:11434，支持自定义主机、端口及 HTTP / HTTPS。
仅填写主机名或 IP 时默认端口 11434；完整 http:// 或 https:// 地址遵循其显式端口，未写端口则使用 80 / 443。请填写服务根地址，不添加 /api/chat；本版不提供 API Key 或登录认证设置。
连接后自动列出该 Ollama 已安装的本地模型，可从下拉菜单选择；刷新连接可重新读取列表。模型不随桌宠分发，也不会由桌宠自动下载。
图片功能按模型声明的能力启用；已明确不支持聊天或识图时会显示提示。旧服务未声明能力时允许尝试，由服务返回结果。
更换服务地址会停止回复，保存当前记录和草稿，并打开新地址自己的会话，避免旧对话自动发送至新服务器；测试连接只查询模型信息，不发送聊天和图片。测试失败不会覆盖原地址。
聊天和图片发送到所配置的 Ollama。默认地址表示当前电脑；填写另一台电脑的地址时，内容会发送到那台电脑。启用联网时，搜索关键词另发往搜索服务，公开网页资料交给模型。新电脑须安装并启动 Ollama、下载模型，或填写已有可访问的 Ollama 地址。

1.8.2 独立桌面进程与配对目录

1.8.1 启动重连与退出诊断
配对文件暂时被占用或无法读取时暂停请求并自动重试，不再把临时读取失败误判为已清除连接、停止后台刷新或要求首次配对。
真实清除、缺失或过期的配对仍需要主动配对；不安全的文件权限、路径或签名仍拒绝连接。
新增本机运行日志 %LOCALAPPDATA%\AIPet\lifecycle.jsonl，记录启动、退出、会话结束、显示恢复和连接恢复，方便排查桌宠消失。当前日志与上一份日志各最多 128 KiB，总计最多 256 KiB；不保存任务、消息正文、管道地址或配对材料。

1.8.0 Codex / Dot 任务分流
工作看板增加 Codex、Dot、全部三种来源筛选，启动时默认 Codex。切换只影响看板，不改变主桌宠关注的范围。
主桌宠的任务数量、工作动画、气泡与完成提醒只跟随 Codex；Dot 和来源待确认的任务不会触发主桌宠工作或打断散步。
任务列表接口暂未提供完整的 Dot 归属信息。普通本地任务归为 Codex；缺少可靠归属的远程任务仅显示在“全部”中并标记“来源待确认”，不会凭标题或远程地址猜成 Dot。
在“全部”中右键任务，可选择“归入 Codex”“归入 Dot”或“自动识别来源”。手动归类按任务身份保存，刷新和重启后保留；无需开启消息读取。

余额、周额度仍属于账户，来源筛选不会把它们划分成独立额度。
已预留 Dot 独立任务状态和动画意图接口；本版不开启 Dot 悬浮形象、窗口或动画，也不增加独立轮询。

1.7.5 Windows App / 远程桌面兼容
远程会话已连接且未锁定时，桌宠继续播放场景动画并执行行走、跳跃、下落；远程桌面自动关闭 Windows 界面动画不会再停住桌宠。
呼吸动画仍由独立开关控制，关闭呼吸不影响场景动画和桌面行走；本地会话继续遵循 Windows 减少动画设置。
仅处理桌宠所在 Windows 会话的连接与锁定状态；切换到远程桌面时重新读取当前会话，避免被旧的本地关屏或锁定状态卡住。
远程连接期间不因家里物理显示器关闭而暂停；远程会话断开、锁定或电脑休眠时仍暂停，恢复后重建动画。所有恢复次数限制继续生效。

1.7.4 关闭显示器后的渲染保护
发行包升级为自包含 .NET 10 Desktop Runtime，包含微软对显示器关闭或不可用时 D3DImage 渲染线程故障的底层修复。
此更新针对关闭全部显示器、屏幕断开与恢复后出现的 UCEERR_RENDERTHREADFAILURE（0x88980406）问题。
收到关屏、休眠或锁屏通知时暂停动画与移动，并释放浏览器渲染控件；显示与会话恢复后延迟重建，隐藏桌宠期间不重建或自动显示。
每轮浏览器恢复最多尝试 3 次；持续异常时，在没有新的显示状态变化或手动重新选择的情况下，每 10 分钟最多开启 3 轮恢复，之后保留静态角色与原选择。
若 WPF 渲染线程仍出现该致命错误，程序保存设置并退出失效进程，每 10 分钟最多自动重启 2 次；第二次进入静态显示兼容模式，暂停动画和移动。
兼容模式只影响本次进程，原皮肤、模型、动作与连接偏好继续保留。显示设备稳定后，可从托盘退出并手动重新启动以重试动画；恢复达到上限时不再循环重启。
运行库随发行包提供，其他电脑无需另装 .NET 或 SDK；动画与 Live2D 仍使用 Microsoft Edge WebView2 Runtime。
不需要更改系统显卡设置或全局关闭硬件加速，已有连接、皮肤、动画和外观偏好继续保留。

1.7.3 始终置顶恢复
开启“始终置顶”后，桌宠会在其它窗口切换、最小化恢复及层级变化时合并检查，并使用低频检查兜底恢复置顶状态。
恢复仅调整桌宠自身的窗口层级，不抢占键盘焦点，不改变桌宠位置和大小；菜单及系统临时界面打开时暂缓恢复。
关闭置顶或隐藏桌宠后停用恢复，隐藏的桌宠不会自行出现；从托盘手动显示后按当前设置恢复。
置顶恢复独立于呼吸动画、桌面行走和 Codex 连接，不需要同时开启这些功能。

1.7.2 连接刷新恢复与界面版本
界面通知或渲染回调异常不会再占住刷新锁、跳过其它界面更新，或被误认为 Codex 断线。
真实连接失败时继续自动重试，连接状态中显示重试间隔。任务正常刷新仍为 5 秒、额度 60 秒。
桌宠、工作看板、设置、Live2D 库、场景动画库、托盘和右键菜单统一从运行程序读取版本号。
桌宠的独立版本标签在隐藏状态条或显示提示气泡时仍可见。

• 任务范围是 App 返回的最近 50 个非置顶任务，加上全部置顶任务，再筛选其中的 Codex 任务。
  可以搜索标题或项目，筛选运行中、需要关注和已空闲任务；不读取普通 ChatGPT 聊天。

  点击“立即刷新”或按 F5 可立即检查连接、额度和任务。
• 开启对话读取后，核验等待审批、等待输入、任务完成或异常等变化并显示桌宠/托盘提醒。
  看板底部的通知开关可关闭这些提醒，后台读取仍继续。
• 断线时保留上次读取的内容，并显示断线或未更新提示及最近刷新时间。

Live2D 需要 Microsoft Edge WebView2 Runtime，本机已安装；详见“Live2D说明.txt”。

桌宠操作
• 左键拖动：移动位置，DeepSeek 会播放拎起与循环挣扎；鼠标滚轮：放大或缩小。
• 左键：表情互动，连续点击三次起生气；点击下方状态条：工作看板；右键：在人物左侧展开对话、设置、看板、更多图标，靠边自动换侧。
• 聊天面板可拖入图片；按 Esc 或点击“×”收起。关闭、重启或新对话均保留旧记录，可从“历史”切换；换肤、大小、置顶、动画等操作在“更多”中。
• 中键：开启或关闭呼吸/眨眼；PNG 为呼吸效果，Live2D 为已有参数的眨眼与呼吸。
  Live2D 关闭后恢复默认参数；此开关不影响“桌面行走与窗口互动”。
  系统开启“减少动态”时暂停桌面移动与场景播放，Live2D 保持默认姿势。
• “回到屏幕角落”：找回桌宠并放到屏幕角落。

隐藏、穿透与托盘
任务栏右侧通知区域有“AiPet 桌宠”图标，找不到时打开隐藏图标区域。
右键托盘可显示/隐藏桌宠、打开聊天、工作看板或“皮肤与设置…”。双击托盘可显示桌宠。
开启“鼠标穿透”后，点击会落到角色后面的窗口，无法直接操作桌宠。
恢复互动：右键托盘 →“皮肤与设置…”→ 取消勾选“鼠标穿透”。
隐藏后从托盘“显示桌宠”恢复，或在设置面板点击“唤回桌宠”。
彻底退出请右键托盘选择“退出桌宠”，或右键人物 →“更多”→“退出桌宠”。
本版本不会设置开机自启，退出后需要再次手动启动。

设置与连接
外观、位置、动画、穿透、刷新间隔和通知偏好会自动保存到：
  %LOCALAPPDATA%\AIPet\settings.json
本机连接记录位于：
  %LOCALAPPDATA%\AIPet\connection.dat
需要恢复默认外观时，先退出桌宠，再删除 settings.json。
连接记录由当前用户 DPAPI 加密，仅含端点、真实任务/轮次上下文与时间，不保存对话、余额或登录凭据。

完成首次配对后，普通双击可使用本机记录连接，端点失效后会尝试重新发现。
换到新电脑时，需要在那台电脑的 Codex 中提供一次真实本机调用上下文后建立连接记录；
仅复制程序无法代替首次配置，也不要分发任何人的 connection.dat、connection.json 或撤销记录。
接入使用 Codex 当前版本的内部只读接口，App 升级可能需要更新适配。
桌宠不会发送消息、继续任务、执行审批、花费 Credits 或兑换额度重置。

复制给其他电脑
推荐分发 releases\AI-Pet-1.9.0-win-x64-extract.exe 或 AI-Pet-1.9.0-win-x64-portable.zip，完整解压后双击启动。
更新时先从托盘退出旧版；已有实例运行时，启动新版只会打开旧实例的看板。
也可完整复制 dist 文件夹，保留 DLL、runtimes 和所有 assets 子文件夹，随后运行 DesktopPet.exe。
目标电脑需要 Windows 11 x64；发行包已包含 .NET 10 Desktop Runtime（x64），动画与 Live2D 另需 WebView2 Runtime。
缺少 WebView2 时运行发行包 redist 中的微软安装程序。只复制 DesktopPet.exe 无法正常运行，必须保留完整解压内容。
桌宠外观可以独立使用；Codex 看板还需要本机已登录的 Codex App 和上述首次连接配置。


场景动画与桌面移动（1.3.2）
右键人物 → 更多 → 场景动画与导入…：导入 .petanim.json，预览并选择自动工作 / 完成动画。详见动画说明.txt 与动画包清单示例.txt。
自动完成动作沿用 Codex 最新轮次核验，失败、中断和单纯变为空闲不会当作成功庆祝。
右键人物 → 更多，或在外观设置中选择“桌面行走与窗口互动”：开启后可在工作区和可见窗口顶边行走；支持拖放抛出、下落与跟随承载窗口。
承载窗口左右移动或向上移动时保持跟随；窗口顶边向下移动时，桌宠脱离支撑并按重力下落，不会被窗口直接拉下去。下落追上窗口顶边后可重新落稳。
跳到附近窗口：从已有落脚点尝试跳往同屏可达的窗口顶边；没有合适目标时会提示。尚不支持跨多窗口路线规划。
升级默认不打开自动移动；移动开关关闭后保留当前位置。呼吸/眨眼开关与移动独立，关闭呼吸后仍可下落和跟随窗口。
隐藏桌宠或系统关闭动态效果后暂停移动与场景播放；打开右键菜单时暂时停止移动，关闭菜单后继续。
DeepSeek 已内置待机、工作、向左走、向右走、下落、落地、拎起挣扎及唱歌八个动画状态，无需导入。前七种状态跟随任务与移动，唱歌由手动操作开始。任务执行时工作，任务空闲或连接断开时待机；工作时暂停自主行走。开启移动后，走路画面与移动方向自动对应。其他八个角色保持原有显示。
脚点根据角色可见像素的透明度估计，不再使用显示容器底边；PNG 呼吸以该脚点为支点。
落地对齐显示器实际工作区底边（通常是任务栏上沿），透明窗口留白不再把角色垫高。靠近窗口顶边低速释放可吸附。
窗口位置跟随 WPF 实际显示帧更新；实际流畅度取决于显示刷新率、系统负载及渲染状态，不保证固定 60 FPS。
复杂透明窗仍按矩形边框近似；带大阴影、脚下装饰或特殊姿势的素材，自动估计的脚点仍可能需要素材适配。

下落与落地动画（1.5.0）
开启桌面行走与窗口互动后，把 DeepSeek 拖到空中松开即可下落。角色离开支撑面时播放下落循环，碰到可落脚窗口顶边或桌面工作区底边时播放一次落地缓冲，再恢复待机或工作。工作中的角色同样遵循下落、落地优先的顺序。
落地缓冲期间暂停自主行走；拖拽、再次下落或关闭移动会打断该动作。其他角色保持原有显示。
