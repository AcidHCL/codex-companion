桌宠声音与语音输入（1.30.1）

分开的生成方式与音色列表（1.30.1）
设置 → 模型与语音：“语音生成方式”只选择关闭语音、使用已保存音色（Base）、使用预置说话人（CustomVoice）、按文字即时生成（VoiceDesign），点击“应用生成方式”保存。具体音色名称不再混在这个下拉框中。
下方“已保存音色”直接以名称列出两项内置默认与该角色自定义音色，保护标记和保存时间作为第二行信息。选中名字，点击“使用所选音色”即可启用；自定义音色可重命名或删除。Let Me Go 和 GPT 龙娘固定音色继续受到保护。
未选择或已丢失的音色不会自动替换为其他声音。音色工坊仍支持命名生成结果后保存；旧的音色 ID、角色选择和参考音频继续沿用。

命名音色库（1.30.0）
在“设置 → 模型与语音”选择要编辑的角色，音色库列出内置音色与该角色全部已保存音色。可切换使用、重命名或删除自定义音色；同名音色会通过保存日期和短 ID 区分。重命名只更新显示名称，不重新生成音频。
工坊生成、试听满意后，填写 1–60 字的“保存名称”，再点击“固定并保存使用”。修改名称不需要重新生成试听。以前保存的无名称音色会自动显示角色与保存日期，参考音频及引用 ID 保留。
Let Me Go 是 DeepSeek 默认音色，GPT 龙娘固定音色是 GPT 默认音色；两项内置音色始终保留，不能手动删除或重命名。已有明确保存的角色选择（包括关闭语音）保持不变。
删除正在使用的自定义音色时，引用该音色的角色会先切回各自默认值（其他角色默认关闭语音），再将音色移出列表。删除不涉及语音模型权重；本机 voices 目录的 .trash-<引用 ID> 保留恢复副本。重新打开设置及重启程序仍保留名称与选择。

以下按版本保留功能记录，历史界面名称与当时默认值可能不同；当前操作以以上 1.30.1 说明及 README 教程为准。

独立设置页（1.29.0）
语音开关、音量、模型加载与显存、每角色音色和音色工坊现统一位于“设置 → 模型与语音”。从桌宠右键图标栏、工作看板、换装页或托盘均可打开设置。切走模型页、隐藏或最小化设置窗口会停止模型状态轮询与试听；关闭设置会取消未完成的工坊生成，已固定音色仍保留。

音色工坊（1.28.0）
设置 → 模型与语音 → 每个角色的声音：先选择编辑角色，再到“音色工坊”输入音色描述、试听台词与语言。点击生成后，可反复试听同一段候选音频；修改描述后需重新生成。只有点击“固定并保存使用”才会替换该角色的声音。关闭设置前未保存的候选仅存在内存中。
生成需要已下载的 VoiceDesign 1.7B，固定后用 Base 1.7B 参考克隆，后续无需重复描述音色。工坊生成或试听会暂停普通语音并释放当前语音模型，结束后恢复按需朗读；不修改 Ollama 设置，也不卸载聊天模型。可以取消生成或停止试听。
固定音色的 WAV、准确试听台词、描述与元数据保存在本机 %LOCALAPPDATA%\AIPet\voices，每次保存独立版本；角色设置仅记录引用 ID。升级程序保留该目录；换电脑时需同时复制角色设置与 voices 目录。此目录不应加入公开源码包。DeepSeek 与 GPT 原有音色不会自动替换。
参考音频固定的是说话人音色，新的台词仍会有自然语调变化。试听建议使用 20–80 字自然台词；有效参考须为 1–30 秒。首次生成需加载模型，速度与当前显存负载有关。

GPT 龙娘固定音色（1.27.1）
在“每个角色的声音”中选择“Base 1.7B · GPT 龙娘固定音色”并保存。该选项复用 Base 权重，以随包附带的 GPT 专属 reference.wav + reference.txt 做 ICL 语音克隆，后续朗读不再调用 VoiceDesign 或重复音色描述。最初的文字设计提示词保存在 references/gpt-dragon-v1/reference-info.json 中；每次说话的语调仍会自然变化。DeepSeek 的 Let Me Go 参考音频和原有克隆方式保持独立。
固定音色需要已安装 Base 模型；使用固定音色时不需要加载 VoiceDesign。

按角色选择声音（1.27.0）
在看板右上角打开“模型与显存”，找到“每个角色的声音”。选择 DeepSeek、Gemini、Claude、GPT、Grok、GLM、Kimi、MiniMax 或 Qwen，选择声音模型，编辑所需音色 / 描述后点击“保存此角色声音”。这里选择的是编辑对象，不会切换桌宠皮肤或 Ollama 模型。保存配置本身不加载模型；切换到该角色后，按当前语音开关和聊天保留策略使用。
提供“不启用此角色语音”及三种声音模型：Base 1.7B 使用原有 Let Me Go 参考音色；CustomVoice 1.7B 直接选择 9 种固定说话人，可填写语气要求；VoiceDesign 1.7B 根据文字描述生成音色，不需要参考音频。VoiceDesign 多次或跨句生成的音色可能存在差异，不能当成已固定的专属声音。
旧设置升级时 DeepSeek 仍使用 Base 与原参考音色，其余角色默认关闭，需自行选择并保存。为其他角色选 Base 也会使用同一 Let Me Go 音色，不会自动生成该角色的新音色。
看板底部现称“桌宠语音播报”，是所有角色共用的总开关和音量；每个角色的声音模型独立保存。预加载、卸载、试听始终针对当前桌宠角色，不针对下方正在编辑的其他角色。切换当前角色的声音会停止旧播报并回收旧语音工作进程，下一次朗读使用新配置；不会修改或自动卸载 Ollama。
模型显存区域显示语音服务当前实际加载的模型名称。查看状态或编辑非当前角色不会加载模型。

下载额外声音模型
在源码根目录使用已经安装好的语音 Python 环境运行：
& .\.tools\deepseek-voice-fast-venv\Scripts\python.exe .\desktop-pet\voice-service\download_model.py --model voice-design
& .\.tools\deepseek-voice-fast-venv\Scripts\python.exe .\desktop-pet\voice-service\download_model.py --model custom-voice
也可以使用 --model all 下载三种模型；不加 --model 时仍只下载 Base。下载不加载 GPU 模型，不上传音频或对话。模型保存在 .tools\deepseek-voice-models，各模型互不覆盖。运行时仍保持离线。

以下保留各历史版本说明；角色范围、界面名称和声音模型选择以以上最新版本说明为准。

同步选模与显存分色（1.24.0）
看板“模型与显存”可通过下拉框选择当前 Ollama 服务已安装的 LLM，与聊天面板即时双向同步，保留当前对话和草稿。选中不等于预加载；可点击“加载 LLM”，或在下一次发送消息时按需加载。语音模型与聊天模型仍分别控制。
显存图例按已加载模型用不同颜色列出名称和占用量，并区分语音、其他 / 未归属以及空闲。语音分色只计 PyTorch 已保留量，已分配量已经包含在其中，不会重复相加；服务未提供的占用保留为未知。
多卡采用本机汇总，远程 Ollama 单独显示。驱动总量、Ollama 和 PyTorch 的采样时间及统计范围不同，数字无法对齐时会明确提示差异。此改动不改变音色、语音保留策略或 Ollama 全局设置。

模型与显存看板（1.23.0）
从看板右上角打开“模型与显存”，分别加载 / 卸载当前语音模型和聊天中选中的 LLM；语音加载需要先启用 DeepSeek 语音播报。页面显示模型实际状态及显存信息，只有页面可见时每 5 秒查询，查看状态不会加载模型。
语音显示 PyTorch 已分配和已保留显存，保留量包含可复用缓存。Ollama 显示服务返回的模型显存与总驻留量；本机 NVIDIA 显卡显示驱动统计的已用 / 总量及利用率，其中包含其他程序，不能直接用各模型数值相加对照。
远程 Ollama 的模型显存属于远程服务器；本机总显存查询为可选功能。服务或驱动未提供的数字显示“未提供”或具体原因。
卸载语音会停止播报，卸载 LLM 会影响使用同一 Ollama 模型的其他软件；两者都不删除模型文件。Ollama 全局设置和自动保留时长保持原样。

点击与播报优先级（1.22.2）
未开启 LLM 行为控制时，点击 DeepSeek 的预设回应也会朗读，仍遵守看板的语音开关。
新的一条预设回应、点击回应或模型回答会立即停止旧播报并取消旧合成，不再等旧话说完；新声音仍需等待其首段合成。
同一条模型回答内部的句子保持连续播放。被打断的旧回答、迟到音频或取消回执不会恢复或误停新的播报。

模型加载控制
看板“DeepSeek 语音播报”一栏可手动预加载或卸载语音模型；卸载会停止当前声音，但不会删除模型文件。
启用 DeepSeek 语音后，打开聊天时会预热语音模型，聊天窗口保持打开期间持续保留；关闭/隐藏聊天后恢复空闲释放。
手动卸载优先，不会因为聊天窗口仍打开而马上重新加载；下一次朗读或主动预加载时再加载。
聊天框“聊天模型”一栏可预加载或卸载当前选中的 Ollama 模型，两组按钮互相独立。
LLM 预加载使用桌宠原有 8K 上下文，不修改 Ollama 全局配置或自动保留时长；正常聊天请求沿用原有设置。
LLM 卸载是一次显式释放请求，不会删除已下载模型；下一次发送消息会按原有方式自动加载。

唱歌与朗读
启用模型行为控制后，明确的“唱首歌”“唱 Let Me Go”“别唱了”等短指令会直接请求对应动作，并检查实际执行结果。
拖拽、下落、用户手动演出等状态仍受原有保护；模型只能按实际回执回答。
歌曲使用场景声音开关，回答朗读使用 DeepSeek 语音播报开关，两个开关独立。

语音输入（1.20.0）
打开和桌宠的聊天框，点击图片按钮旁的麦克风开始录音，再点一次结束并转成文字。
使用 Windows 默认输入设备；录音中按钮变红并显示秒数，最长 60 秒自动停止。
转写只追加到当前输入框，原有草稿和图片保留。可以修改错字，确认后按发送；不会自动提交。
按 Esc 取消当前录音或识别；识别期间再次点击麦克风也可取消。
关闭/隐藏聊天、切换对话/角色/模型、锁屏或休眠会取消语音输入，旧结果不会进入新对话。
只在主动点击后使用麦克风。录音时暂停桌宠播报，有声场景播放会停止，以避免录入桌宠自己的声音。
语音输入与看板的“DeepSeek 语音播报”开关独立，所有角色聊天均可使用语音输入。
当前使用本机 faster-whisper-small，多语言识别，主要用于中文和英语；CPU int8，不占用显存。
本机固定 6.2 秒样本约 3.5 秒完成转写，包含启动进程和加载模型；实际速度与录音长度有关。
人名、专有名词和同音字可能识别错误，请发送前检查文字。
录音只保留在内存，经私有进程管道交给本地模型，不保存原始录音、不上传识别服务。
确认发送后，文字沿用当前 Ollama 地址、联网设置和本地聊天记录规则。
若无法录音，请检查 Windows 默认输入设备，以及是否允许桌面应用使用麦克风；程序不会自动改变权限。
换电脑时需另装 asr-service 对应 Python 环境和约 486 MB 模型，说明与安装脚本在 asr-service 中。

使用
在看板底部打开“DeepSeek 语音播报”，可分别调整语音音量、试听及停止朗读。
此开关与唱歌/场景声音开关独立，偏好会保存。当前仅适配 DeepSeek。
任务完成等预设提示和本地模型的可见正文会朗读；加速后端收到完整的句子或段落后开始合成，无须等整条回答结束。
不朗读思考过程、工具规划、引用编号、网页地址、代码块及重新打开的历史对话；未闭合的 Markdown 暂缓处理。
新消息、切换对话和关闭聊天会停止旧回答；关闭语音会立即停止。
隐藏桌宠、锁屏或播放有声歌曲时暂停，不在恢复后补读积压消息。

音色
使用本机 Qwen3-TTS-12Hz-1.7B-Base，通过 Let Me Go 原音频分离出的 9 秒人声提取参考音色。
没有上传歌曲、聊天或生成声音。保留参考的自然音高，不靠变速提高声音。
歌曲与口语的发声方式不同，音色相似度需要实际试听确认，不保证逐字复现歌手声音。
1.21.0 的加速后端复用相同的 1.7B 权重、参考人声和声纹模式，不改语速或音高，不切换到其他声音。
加速后端按音频块连续输出，播放器使用同一个声音设备和约 1 秒初始缓冲；若供给变慢会适当增加缓冲。
正文生成和语音生成可并行。实际开口时间还受聊天模型首段输出、冷启动和显卡负载影响。
语音总长度有 64 MiB 上限，超过会显示错误并保留文字；声音设备或合成失败不会删除对话。
聊天期间保留语音模型；离开聊天后空闲 60 秒释放，客户端意外退出时保留租约也会到期。
预加载会占用显存，首次加载/预热仍需要等待；不会为语音自动卸载 Ollama 聊天模型。
旧后端基准：生成 6.2 秒声音约需 10.5 秒，显存峰值约 4.2 GiB。新后端速度以本机验证报告为准。

隐私与本机服务
本地服务只监听 127.0.0.1:18766，使用每次启动新建的令牌，拒绝网页跨域请求。
桌宠退出时终止自己启动的语音进程；父进程异常退出时服务也会退出。
流式音频在有界内存队列中播放，不保存聊天音频、不写入历史库。
如切回旧后端，整段 WAV 临时存放于 %LOCALAPPDATA%\AIPet\voice-temp，结束/停止时删除。

换电脑
普通桌宠包不内嵌数 GB 的语音模型和 Python/CUDA 依赖。
仅复制 EXE 或 dist 文件夹不会一并复制本地语音运行环境；文字聊天和原有功能仍可使用。
部署语音请查看 voice-service 目录的安装说明和脚本，准备兼容的 NVIDIA GPU、Python 3.12、CUDA版 PyTorch 和官方模型。
voice-service/reference.wav 是当前参考音色，config.json 指向模型和参考文件。
安装完成前可关闭语音开关；服务故障会显示在看板状态栏，不使用其他音色冒充参考音色。
