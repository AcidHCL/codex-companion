AI Pet 1.21.0：首次使用

本说明适用于已构建的完整程序目录。源码包请先按 README.md 构建；源码 ZIP 本身不是安装程序。
Windows 11 x64；普通构建需要 .NET 10 Desktop Runtime，只有自行发布的 self-contained 程序才自带运行时。动画、视频与 Live2D 还需要 Microsoft Edge WebView2 Runtime。

启动与操作
完整解压后启动 DesktopPet.exe，不要单独移动该文件；assets 和运行库需要保留在同目录。
右键人物展开“对话 / 设置 / 看板 / 更多”图标；双击人物打开聊天。通过设置换皮肤、调大小、置顶或启停桌面行走和窗口互动。退出使用系统托盘菜单。
DeepSeek 的待机、工作、行走、拖拽、下落、落地、情绪和表演动作取决于实际随包素材。动画面板可选择已安装的新版或旧版。
不连接 Codex 或本地模型也可使用桌宠基本功能。

Codex
按 Codex首次连接.txt 完成配对，需要同一电脑、同一 Windows 用户与会话中的官方 Codex App。
默认查询额度和任务，消息正文需单独开启。看板可筛选 Codex / Dot / 全部，主桌宠只提醒 Codex 任务。
内部接口可能随 Codex 更新而变化。身份或签名检查失败时不连接，不要绕过验证。换电脑或 Windows 用户必须重新配对。

聊天与记忆
先安装并启动 Ollama，下载适合自己硬件的模型。聊天面板默认连接 http://127.0.0.1:11434，可配置其它服务根地址；不要添加 /api/chat。
测试成功后保存，自动读取目标服务已安装模型。只有支持图片的模型才启用图片输入；可拖入、选取或粘贴图片。
聊天模型“预加载 / 卸载”只控制所选模型，不删除权重，不修改 Ollama 全局配置或自动保留时长。
“历史”可恢复、新建、重命名或删除会话；“记忆”可管理跨会话共享信息。完整记录保留，推理时按上下文容量选择近期内容。
开启“联网”时搜索词发往搜索服务，公开网页正文交给所选模型；需登录、验证码或动态网页可能无法读取。
配置远程 Ollama 时，消息与处理后的图片会发往该地址；当前不支持 API Key 或登录认证设置。

声音
“音乐与声音”控制场景歌曲；看板“DeepSeek 语音播报”控制提示与回答朗读，开关独立。
语音环境和模型需另外安装，参见便携语音说明.txt。默认 faster 后端复用原权重与参考人声，连续输出音频，不额外改变音高或语速。
看板提供语音预加载、卸载、试听、停止和音量。打开聊天可预热并保留语音模型；离开后恢复空闲释放，手动卸载优先。
语音与 Ollama 聊天模型独立，不会为语音自动卸载聊天模型。首次加载、硬件负载和模型自然停顿会影响开口时间。
点击麦克风开始录音，再点一次结束；识别文字进入输入框，由使用者确认后发送，最长60秒，Esc可取消。
识别使用本地多语言 Whisper small / CPU int8，不占聊天显存。录音只在主动操作后开始，不上传识别服务或保存原始录音。

数据与迁移
设置、配对、聊天数据存放于当前用户的 %LOCALAPPDATA%\AIPet，此通用位置不是随包数据。
聊天正文与图片、配对材料按 Windows 当前用户加密。配对记录90天有效，成功重连会刷新。
“断开并清除”撤销连接，恢复需要主动重新配对。临时断线先重试，不必清除配对。
请转发原始干净包，不附带自己的 AppData、数据库、日志、venv、下载缓存或连接材料。

常见问题
动画不显示：检查 assets 是否完整、WebView2 是否安装。
无声音：检查对应开关、Windows 输出设备与音量；远程桌面需要允许远程声音。
语音引擎未安装：准备相应 Python 环境及模型；不影响文字聊天。
未连接 Codex：确认 App 运行且联网、配对有效；不要关闭身份校验。
关屏或远程会话恢复异常：设备稳定后从托盘退出，再启动桌宠。
